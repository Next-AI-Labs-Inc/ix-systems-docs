# Document Organization Guide for AI Agents

## Directory Structure

This `/Users/jedi/react_projects/ix/ixcoach-api/docs/` directory is the central location for all API-related documentation. When adding new documentation, please follow these guidelines:

### Main Documentation Categories

- **Core API documentation** - Place directly in this directory
- **Proposed changes/features** - Place in the `proposed/` subdirectory
- **Issues and bug reports** - Place in the `issues/` subdirectory
- **IXC (gptcoach2) documentation** - Place in the `ixc/` subdirectory
- **IXC issues** - Place in the `ixc/issues/` subdirectory

### Organization Principles

1. **Topical organization** - Group related documents together
2. **Clear naming** - Use descriptive filenames with dates when appropriate (YYYY-MM-DD-title.md)
3. **Linking** - Maintain references between related documents

## Documentation Types

- **Guides** - Comprehensive explanations of features or processes
- **Issues** - Detailed descriptions of bugs, problems or investigations
- **Proposed solutions** - Documentation for features or changes that are not yet implemented 

## Best Practices

1. **Update existing documentation** rather than creating duplicate documents
2. **Link to related files** when referencing other components
3. **Keep documentation close to code** - if the documentation is specific to a component, place it near that component
4. **Use consistent formatting** across all documentation files

This structure ensures all documentation is organized in a clear and consistent manner.
