# Document Organization Guide for IXC (gptcoach2)

## Directory Structure

This `/Users/jedi/react_projects/ix/ixcoach-api/docs/ixc/` directory is the central location for all IXC (gptcoach2) documentation. When adding new documentation, please follow these guidelines:

### Main Documentation Categories

- **Core IXC documentation** - Place directly in this directory
- **IXC issues** - Place in the `issues/` subdirectory

### Issue Subcategories

- **Firebase auth issues** - Place in the `issues/firebase_auth_issues/` subdirectory
- **Circular dependencies** - Place in the `issues/circular_dependencies/` subdirectory

1. **Update existing documentation** rather than creating duplicate documents
2. **Link to related files** when referencing other components
3. **Use consistent formatting** across all documentation files
4. **Categorize issues properly** to ensure they can be found easily

This structure ensures all IXC documentation is organized in a clear and consistent manner.
